## Como penso o trabalho

Gosto de transformar processos repetitivos em fluxos auditáveis: primeiro perceber a regra contabilística, depois estruturar os dados, gerar o ficheiro e validar antes de entregar.

A minha prioridade é que cada automatização seja prática para o dia a dia: clara, reproduzível, conferível e segura.

## Áreas de interesse

- Validação de ficheiros de integração contabilística
